# Convert colour name to hexadecimal

Convert colour name to hexadecimal

## Usage

``` r
col2hex(color_name)
```

## Arguments

- color_name:

  Character. Colour name recognised by R.

## Value

Character. Hexadecimal colour code.

## Examples

``` r
col2hex("forestgreen")
#> [1] "#228B22"
col2hex("blue")
#> [1] "#0000FF"
```
