# The urbioconnect map colours

The palette the package's maps use, so a map downloaded from the Shiny
app matches the one on screen. Based on scico's tofino palette.

## Usage

``` r
urbio_colours()
```

## Value

A named list of colours: `habitat`, `interpatch_distance` and `barrier`.

## Examples

``` r
urbio_colours()
#> $habitat
#> [1] "#183219"
#> 
#> $interpatch_distance
#> [1] "#8FBD73"
#> 
#> $barrier
#> [1] "#FFFFFF"
#> 
```
